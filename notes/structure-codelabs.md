# Titulo orientado a la accion

	¿Qué aprenderá el estudiante? / objetivos del aprendizaje
	¿Qué conocimientos previos necesita?
	¿Qué producto final obtendrá?

2. Establecer los prerrequisitos
	Indica claramente qué necesita tener instalado:
	Sistema operativo compatible.
	Lenguaje y versión.
	Frameworks.
	Base de datos.
	Editor de código.

3. Describir el resultado esperado
	Muestra al estudiante qué construirá.

Es recomendable incluir:
	Capturas de pantalla.
	Diagramas.
	Ejemplos de ejecución

6. Incluir verificaciones
	Después de cada paso, el estudiante debe poder validar que todo funciona.
8. Incluir retos opcionales
	Permiten reforzar el aprendizaje.
10. Finalizar con una recapitulación
Resume lo aprendido.
