En este codelab construiremos una aplicación web para la administración y análisis de un **array con datos numéricos primitivos** aplicada al **Control de Gastos Diarios**.

Pondremos en práctica los fundamentos esenciales:
- Declaración de arrays homogéneos en plural (`gastos`).
- Lectura y cálculo de longitud con la propiedad `.length`.
- Acceso por índice en base cero (`gastos[i]`).
- Algoritmo de acumulación para suma total con bucle `for`.
- Algoritmo de búsqueda de valor máximo (gasto más alto).
- Inserción de nuevos datos con `.push()` y actualización dinámica de la interfaz.

## 3. Declaración del array y referencias DOM

Abrir el archivo `app.js`.

Definimos el array inicial de gastos y capturamos las referencias a los elementos del documento HTML:

```javascript title="app.js" showLineNumbers
const gastos = [15, 30, 45, 20, 10];

const inpGasto = document.getElementById("inp-gasto");

const outLista = document.getElementById("out-lista");
const outTotal = document.getElementById("out-total");
const outMayor = document.getElementById("out-mayor");
```

:::danger
Verifica minuciosamente que los identificadores de texto en `document.getElementById("...")` coincidan letra por letra con los atributos `id` de `index.html`. Un error tipográfico resultará en `null` e interrumpirá la ejecución.
:::

## 4. Funciones de recorrido y lógica

A continuación desarrollaremos funciones puras e independientes para procesar el array utilizando el bucle `for` clásico.

### Formatear y listar los gastos
Recorremos el array desde el índice `0` hasta `gastos.length - 1` construyendo una cadena de texto:

```javascript title="app.js" showLineNumbers
function obtenerTextoGastos() {
  let texto = "";
  for (let i = 0; i < gastos.length; i++) {
    const monto = gastos[i];
    texto = texto + "Bs. " + monto + "  ";
  }
  return texto;
}
```

### Calcular total gastado (acumulador)
Sumamos cada elemento del array en una variable acumuladora inicializada en `0`:

```javascript title="app.js" showLineNumbers
function calcularTotalGastos() {
  let suma = 0;
  for (let i = 0; i < gastos.length; i++) {
    suma = suma + gastos[i];
  }
  return suma;
}
```

### Encontrar el gasto más alto (extremo mayor)
Inicializamos la variable de referencia con el primer elemento (`gastos[0]`) y comparamos secuencialmente contra los demás:

```javascript title="app.js" showLineNumbers
function obtenerGastoMayor() {
  if (gastos.length === 0) {
    return 0;
  }

  let mayor = gastos[0];
  for (let i = 1; i < gastos.length; i++) {
    if (gastos[i] > mayor) {
      mayor = gastos[i];
    }
  }
  return mayor;
}
```

## 5. Event Listeners

Conectamos las funciones con las acciones del usuario a través de eventos `click` en los botones.

### Botón para mostrar la lista de gastos
```javascript title="app.js" showLineNumbers
const btnMostrar = document.getElementById("btn-mostrar");

btnMostrar.addEventListener("click", (evt) => {
  const texto = obtenerTextoGastos();
  outLista.textContent = "Lista de gastos: " + texto;
});
```

### Botón para calcular el total
```javascript title="app.js" showLineNumbers
const btnTotal = document.getElementById("btn-total");

btnTotal.addEventListener("click", (evt) => {
  const total = calcularTotalGastos();
  outTotal.textContent = "Total gastado: Bs. " + total;
});
```

### Botón para obtener el gasto más alto
```javascript title="app.js" showLineNumbers
const btnMayor = document.getElementById("btn-mayor");

btnMayor.addEventListener("click", (evt) => {
  const mayor = obtenerGastoMayor();
  outMayor.textContent = "Gasto más alto: Bs. " + mayor;
});
```

### Botón para registrar un nuevo gasto
Leemos el valor ingresado en el `<input>`, validamos que sea un número positivo, lo agregamos al array con `.push()` y actualizamos la lista en pantalla:

```javascript title="app.js" showLineNumbers
const btnAgregar = document.getElementById("btn-agregar");

btnAgregar.addEventListener("click", (evt) => {
  const valor = Number(inpGasto.value);

  if (!valor || valor <= 0) {
    alert("Por favor ingrese un monto válido y mayor a 0");
    return;
  }

  gastos.push(valor);

  inpGasto.value = "";

  const texto = obtenerTextoGastos();
  outLista.textContent = "Lista de gastos: " + texto;
});
```

:::tip
Al ejecutar `gastos.push(valor)`, el nuevo elemento se ubica al final del array y la propiedad `gastos.length` se incrementa automáticamente en `1`.
:::

1. Abrir el archivo `index.html` en el navegador **Google Chrome**.
2. Presionar <Keycap text="ctrl" /> + <Keycap text="shiftName" /> + <Keycap text="i" /> para abrir las herramientas de desarrollador y seleccionar la pestaña **Console**.
3. Presionar el botón **Mostrar lista**: se deben listar los 5 valores iniciales `[ Bs. 15  Bs. 30  Bs. 45  Bs. 20  Bs. 10  ]`.
4. Presionar **Calcular total**: debe mostrar `Total gastado: Bs. 120.00`.
5. Presionar **Gasto más alto**: debe mostrar `Gasto más alto: Bs. 45.00`.
6. Ingresar `50` en el campo de texto y hacer clic en **Registrar gasto**: la lista se actualizará incluyendo el nuevo monto, y al presionar de nuevo **Calcular total** mostrará `Bs. 170.00` y **Gasto más alto** mostrará `Bs. 50.00`.

:::note
Si la interfaz no responde al hacer clic, abre la consola del navegador con <Keycap text="ctrl" /> + <Keycap text="shiftName" /> + <Keycap text="i" /> para verificar si existen errores en rojo ocasionados por nombres de `id` o variables no coincidentes.
:::
