En este codelab construiremos una aplicación web para registrar y analizar un **array con datos numéricos primitivos** enfocado en el **Registro de Temperaturas Diarias (C)**.

Pondremos en práctica los siguientes conceptos:
- Declaración de colecciones homogéneas en plural (`temperaturas`).
- Acceso por índice en base cero (`temperaturas[i]`) y uso de `.length`.
- Recorrido clásico mediante bucle `for`.
- Algoritmo acumulador para calcular el promedio.
- Algoritmo para encontrar simultáneamente el valor mínimo y máximo.
- Inserción de nuevas lecturas con `.push()` y refresco visual del DOM.

## 4. Funciones de recorrido y análisis

Implementamos funciones independientes para procesar las lecturas utilizando bucles `for` clásicos y la propiedad `.length`.

### Formatear y listar temperaturas
Recorremos el array desde el índice `0` hasta `temperaturas.length - 1` agregando la unidad `C`:

```javascript title="app.js" showLineNumbers
function obtenerTextoTemperaturas() {
  let texto = "";
  for (let i = 0; i < temperaturas.length; i++) {
    const temp = temperaturas[i];
    texto = texto + temp + " ";
  }
  return texto;
}
```

### Calcular promedio térmico
Sumamos todas las lecturas del array y dividimos entre la cantidad total de elementos:

```javascript title="app.js" showLineNumbers
function calcularPromedio() {
  if (temperaturas.length === 0) {
    return 0;
  }

  let suma = 0;
  for (let i = 0; i < temperaturas.length; i++) {
    suma = suma + temperaturas[i];
  }

  const promedio = suma / temperaturas.length;
  return promedio;
}
```

### Determinar temperaturas extremas (mínima y máxima)
Inicializamos `min` y `max` con la primera posición (`temperaturas[0]`) y comparamos secuencialmente contra los elementos restantes:

```javascript title="app.js" showLineNumbers
function obtenerExtremos() {
  if (temperaturas.length === 0) {
    return { min: 0, max: 0 };
  }

  let max = temperaturas[0];

  for (let i = 1; i < temperaturas.length; i++) {
    if (temperaturas[i] > max) {
      max = temperaturas[i];
    }
  }

  return max;
}
```

## 5. Event Listeners

Conectamos la lógica con los botones de la interfaz a través de escuchadores del evento `click`.

### Botón para mostrar la lista de registros
```javascript title="app.js" showLineNumbers
const btnMostrar = document.getElementById("btn-mostrar");

btnMostrar.addEventListener("click", (evt) => {
  const texto = obtenerTextoTemperaturas();
  outLista.textContent = "Registros: " + texto;
});
```

### Botón para calcular el promedio
```javascript title="app.js" showLineNumbers
const btnPromedio = document.getElementById("btn-promedio");

btnPromedio.addEventListener("click", (evt) => {
  const promedio = calcularPromedio();
  outPromedio.textContent = "Promedio: " + promedio;
});
```

### Botón para mostrar la temperatura máxima
```javascript title="app.js" showLineNumbers
const btnExtremos = document.getElementById("btn-extremos");

btnExtremos.addEventListener("click", (evt) => {
  const max = obtenerExtremos();
  outExtremos.textContent = "Temperatura máxima: " + max;
});
```

### Botón para registrar una nueva temperatura
Leemos el input, validamos que no esté vacío, agregamos la lectura con `.push()` y refrescamos la lista:

```javascript title="app.js" showLineNumbers
const btnAgregar = document.getElementById("btn-agregar");

btnAgregar.addEventListener("click", (evt) => {
  const valor = Number(inpTemperatura.value);

  if (isNaN(valor) || inpTemperatura.value.trim() === "") {
    alert("Por favor ingrese un valor de temperatura válido");
    return;
  }

  temperaturas.push(valor);

  inpTemperatura.value = "";

  const texto = obtenerTextoTemperaturas();
  outLista.textContent = "Registros: " + texto;
});
```

:::tip
El método `temperaturas.push(valor)` agrega el nuevo valor al final de la colección y actualiza automáticamente el tamaño del array (`temperaturas.length`).
:::

## 6. Verificar avance

1. Abrir el archivo `index.html` en el navegador **Google Chrome**.
2. Presionar <Keycap text="ctrl" /> + <Keycap text="shiftName" /> + <Keycap text="i" /> para abrir las herramientas de desarrollador y seleccionar la pestaña **Console**.
3. Presionar el botón **Mostrar registros**: se deben listar los 5 valores iniciales `[ 18  24  15  29  21 ]`.
4. Presionar **Calcular promedio**: debe mostrar `Promedio: 21.4`.
5. Presionar **Temperatura máx.**: debe mostrar `Temperatura máxima: 29`.
6. Ingresar `32` en el input y presionar **Registrar temperatura**: se agregará a la lista; al presionar de nuevo **Temperatura máx.** la máxima se actualizará a `32`.

:::note
Si al interactuar con los botones no se actualiza la interfaz, revisa la consola del navegador para verificar que no haya errores tipográficos en los `id` de las etiquetas HTML.
:::
