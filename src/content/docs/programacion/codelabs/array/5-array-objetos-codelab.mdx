En este codelab construiremos una aplicación web para administrar un **Directorio de Usuarios**. Pondremos en práctica los conceptos estudiados: creación de objetos con propiedades en singular y *camelCase*, almacenamiento en un array en plural, acceso a propiedades mediante **notación de punto**, recorrido con el bucle **`for...of`** e inserción dinámica de nuevos objetos mediante formularios HTML.

## 3. Declaración del array de objetos y referencias DOM

Abrir el archivo `app.js`.

Recordemos los estándares aprendidos:
- La constante del array va en **plural**: `users`.
- Cada elemento es un **objeto** con propiedades en singular: `name`, `age`, `activated`.
- El acceso se realiza mediante **notación de punto** (`user.name`, `user.age`, `user.activated`).

```javascript title="app.js" showLineNumbers
// 1. Array de objetos inicial
const users = [
  { name: "Maria", age: 18, activated: false },
  { name: "Jose", age: 22, activated: true },
  { name: "Ana", age: 19, activated: true }
];

// 2. Referencias a los elementos del formulario
const inpName = document.getElementById("inp-name");
const inpAge = document.getElementById("inp-age");
const chkActivated = document.getElementById("chk-activated");
const btnRegistrar = document.getElementById("btn-registrar");

// 3. Referencias a los botones de acción
const btnTodos = document.getElementById("btn-todos");
const btnActivos = document.getElementById("btn-activos");
const btnPromedioEdad = document.getElementById("btn-promedio-edad");
const btnActivarTodos = document.getElementById("btn-activar-todos");

// 4. Referencias a los contenedores de salida
const outResumen = document.getElementById("out-resumen");
const tblUsuarios = document.getElementById("tbl-usuarios");
```

## 4. Funciones de renderizado y lógica

### Renderizar el array de objetos con `for...of`
En `3-array-objetos.md` aprendimos a recorrer colecciones de objetos con el bucle **`for...of`**.

Esta función recibe cualquier lista de usuarios (la lista completa o una filtrada), itera sobre cada elemento `user` y construye filas `<tr>` leyendo sus propiedades con la notación de punto:

```javascript title="app.js" showLineNumbers
function renderizarTabla(lista) {
  let filasHtml = "";
  let numero = 1;

  for (const user of lista) {
    // Lectura de propiedades con notación de punto
    const estadoTexto = user.activated ? "Activo" : "Inactivo";

    filasHtml += "<tr>";
    filasHtml += "<td>" + numero + "</td>";
    filasHtml += "<td>" + user.name + "</td>";
    filasHtml += "<td>" + user.age + "</td>";
    filasHtml += "<td>" + estadoTexto + "</td>";
    filasHtml += "</tr>";

    numero++;
  }

  tblUsuarios.innerHTML = filasHtml;
  outResumen.textContent = "Mostrando " + lista.length + " usuario(s).";
}
```

### Calcular promedio de edad
Recorremos el array sumando el valor de la propiedad `user.age` de cada objeto y lo dividimos entre la cantidad total de usuarios (`users.length`):

```javascript title="app.js" showLineNumbers
function calcularPromedioEdad() {
  if (users.length === 0) return 0;

  let sumaEdades = 0;
  for (const user of users) {
    sumaEdades += user.age;
  }

  return sumaEdades / users.length;
}
```

### Modificar propiedades de los objetos
En `3-objetos.md` vimos que las propiedades de un objeto se modifican asignándoles un nuevo valor. Podemos actualizar la propiedad `activated` de todos los objetos en el array:

```javascript title="app.js" showLineNumbers
function activarTodosLosUsuarios() {
  for (const user of users) {
    user.activated = true;
  }
}
```

## 5. Event Listeners

Conectamos los botones y el formulario con nuestras funciones lógicas:

### Registrar nuevo usuario (Crear objeto e insertar)
Leemos los valores de los inputs, construimos un nuevo objeto literal con sus propiedades y lo agregamos al array `users`:

```javascript title="app.js" showLineNumbers
btnRegistrar.addEventListener("click", () => {
  const nombre = inpName.value.trim();
  const edad = Number(inpAge.value);
  const activo = chkActivated.checked;

  if (nombre === "" || isNaN(edad) || edad <= 0) {
    alert("Por favor ingresa un nombre y una edad válida.");
    return;
  }

  const newUser = {
    name: nombre,
    age: edad,
    activated: activo
  };

  // Insertar el nuevo objeto en el array
  users.push(newUser);

  // Limpiar campos del formulario
  inpName.value = "";
  inpAge.value = "";
  chkActivated.checked = false;

  // Actualizar la vista
  renderizarTabla(users);
});
```

### Mostrar todos los usuarios
```javascript title="app.js" showLineNumbers
btnTodos.addEventListener("click", () => {
  renderizarTabla(users);
});
```

### Filtrar usuarios activos
Creamos un array auxiliar con los objetos cuya propiedad `activated` sea `true`:

```javascript title="app.js" showLineNumbers
btnActivos.addEventListener("click", () => {
  const usuariosActivos = [];

  for (const user of users) {
    if (user.activated === true) {
      usuariosActivos.push(user);
    }
  }

  renderizarTabla(usuariosActivos);
});
```

### Calcular promedio y activar a todos
```javascript title="app.js" showLineNumbers
btnPromedioEdad.addEventListener("click", () => {
  const promedio = calcularPromedioEdad();
  outResumen.textContent = "El promedio es: " + promedio;
});

btnActivarTodos.addEventListener("click", () => {
  activarTodosLosUsuarios();
  renderizarTabla(users);
});
```

5. Probar **Promedio de edad**: debe indicar `19.7 años`.
6. Probar **Registrar nuevo usuario**:
   - Ingresar Nombre: `Luis`, Edad: `25`, y marcar el checkbox.
   - Presionar **Registrar usuario**: la tabla debe actualizarse automáticamente mostrando los 4 registros.
7. Probar **Activar a todos**: el estado de `Maria` debe cambiar de `Inactivo` a `Activo`.
