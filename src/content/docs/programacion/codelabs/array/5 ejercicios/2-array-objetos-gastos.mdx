En este codelab construiremos una aplicación web para el **Control de Gastos Personales**. Pondremos en práctica los conceptos de estructuras de datos en JavaScript: definición de objetos con propiedades en singular y *camelCase*, almacenamiento en un array en plural (`expenses`), acceso mediante **notación de punto**, iteración con el bucle **`for...of`**, cálculo de totales y promedios, y actualización dinámica de una tabla en el DOM.

## 3. Declaración del array de objetos y referencias DOM

Abrir el archivo `app.js`.

Recordemos los estándares aprendidos:
- El nombre del array se escribe en **plural**: `expenses`.
- Cada elemento es un **objeto** con propiedades en singular: `description`, `amount`, `essential`.
- El acceso se realiza mediante **notación de punto** (`expense.description`, `expense.amount`, `expense.essential`).

```javascript title="app.js" showLineNumbers
// 1. Array de objetos inicial con gastos personales
const expenses = [
  { description: "Alquiler", amount: 650.00, essential: true },
  { description: "Streaming", amount: 45.00, essential: false },
  { description: "Luz e internet", amount: 180.50, essential: true }
];

// 2. Referencias a los elementos del formulario
const inpDescription = document.getElementById("inp-description");
const inpAmount = document.getElementById("inp-amount");
const chkEssential = document.getElementById("chk-essential");

// 3. Referencias a los contenedores de salida
const outResumen = document.getElementById("out-resumen");
const tblGastos = document.getElementById("tbl-gastos");
```

## 4. Funciones de renderizado y lógica

### Renderizar el array de objetos con `for...of`
En `3-array-objetos.md` aprendimos a iterar arrays de objetos mediante el bucle **`for...of`**.

Esta función recibe una colección (sea el array completo o uno filtrado), itera sobre cada `expense` y construye las filas `<tr>` extrayendo los valores con la notación de punto:

```javascript title="app.js" showLineNumbers
function renderizarTabla(lista) {
  let filasHtml = "";
  let numero = 1;

  for (const expense of lista) {
    const prioridadTexto = expense.essential ? "Esencial" : "Opcional";

    filasHtml += "<tr>";
    filasHtml += "<td>" + numero + "</td>";
    filasHtml += "<td>" + expense.description + "</td>";
    filasHtml += "<td>" + expense.amount.toFixed(2) + "</td>";
    filasHtml += "<td>" + prioridadTexto + "</td>";
    filasHtml += "</tr>";

    numero++;
  }

  tblGastos.innerHTML = filasHtml;
  outResumen.textContent = "Mostrando " + lista.length + " gasto(s).";
}
```

### Calcular gasto total acumulado
Recorremos el array sumando el valor numérico de la propiedad `expense.amount`:

```javascript title="app.js" showLineNumbers
function calcularTotalGastos() {
  let total = 0;
  for (const expense of expenses) {
    total += expense.amount;
  }
  return total;
}
```

### Calcular gasto promedio
Dividimos la suma total de gastos entre la cantidad de elementos en el array (`expenses.length`):

```javascript title="app.js" showLineNumbers
function calcularPromedioGasto() {
  if (expenses.length === 0) return 0;
  const total = calcularTotalGastos();
  return total / expenses.length;
}
```

### Modificar propiedades de los objetos
En `4-objetos.md` vimos que podemos actualizar las propiedades de un objeto asignándoles un nuevo valor:

```javascript title="app.js" showLineNumbers
function marcarTodosComoEsenciales() {
  for (const expense of expenses) {
    expense.essential = true;
  }
}
```

## 5. Event Listeners

Conectamos los botones y el formulario con las funciones creadas:

### Registrar nuevo gasto (Crear objeto e insertar)
Leemos los valores ingresados, instanciamos un nuevo objeto literal y lo insertamos en el array `expenses` usando `.push()`:

```javascript title="app.js" showLineNumbers
const btnRegistrar = document.getElementById("btn-registrar");

btnRegistrar.addEventListener("click", () => {
  const detalle = inpDescription.value.trim();
  const monto = Number(inpAmount.value);
  const esEsencial = chkEssential.checked;

  if (detalle === "" || isNaN(monto) || monto <= 0) {
    alert("Por favor ingresa una descripción válida y mayor a 0.");
    return;
  }

  const newExpense = {
    description: detalle,
    amount: monto,
    essential: esEsencial
  };

  // Insertar el nuevo objeto en el array
  expenses.push(newExpense);

  // Limpiar campos del formulario
  inpDescription.value = "";
  inpAmount.value = "";
  chkEssential.checked = false;

  // Actualizar tabla en pantalla
  renderizarTabla(expenses);
});
```

### Mostrar todos los gastos
```javascript title="app.js" showLineNumbers
const btnTodos = document.getElementById("btn-todos");

btnTodos.addEventListener("click", () => {
  renderizarTabla(expenses);
});
```

### Filtrar gastos esenciales y opcionales
Creamos arrays auxiliares filtrando por la propiedad booleana `essential`:

```javascript title="app.js" showLineNumbers
const btnEsenciales = document.getElementById("btn-esenciales");

btnEsenciales.addEventListener("click", () => {
  const gastosEsenciales = [];
  for (const expense of expenses) {
    if (expense.essential === true) {
      gastosEsenciales.push(expense);
    }
  }
  renderizarTabla(gastosEsenciales);
});

const btnOpcionales = document.getElementById("btn-opcionales");

btnOpcionales.addEventListener("click", () => {
  const gastosOpcionales = [];
  for (const expense of expenses) {
    if (expense.essential === false) {
      gastosOpcionales.push(expense);
    }
  }
  renderizarTabla(gastosOpcionales);
});
```

### Calcular total, promedio y marcar todos
```javascript title="app.js" showLineNumbers
const btnTotalGastos = document.getElementById("btn-total-gastos");

btnTotalGastos.addEventListener("click", () => {
  const total = calcularTotalGastos();
  outResumen.textContent = "Total: Bs. " + total.toFixed(2);
});

const btnPromedioGasto = document.getElementById("btn-promedio-gasto");

btnPromedioGasto.addEventListener("click", () => {
  const promedio = calcularPromedioGasto();
  outResumen.textContent = "Promedio: Bs. " + promedio.toFixed(2);
});

const btnMarcarEsenciales = document.getElementById("btn-marcar-esenciales");

btnMarcarEsenciales.addEventListener("click", () => {
  marcarTodosComoEsenciales();
  renderizarTabla(expenses);
});

// Render inicial al cargar la página

```
