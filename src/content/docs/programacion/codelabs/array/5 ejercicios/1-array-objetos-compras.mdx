En este codelab construiremos una aplicación web para administrar **Compras Personales**. Pondremos en práctica los conceptos estudiados: creación de objetos con propiedades en singular y *camelCase*, almacenamiento en un array en plural (`purchases`), acceso a propiedades mediante **notación de punto**, recorrido con el bucle **`for...of`** e inserción dinámica de nuevos objetos mediante formularios HTML.

Presionar la tecla <Keycap text="windowName" /> y abrir la terminal **Git Bash**.

## 3. Declaración del array de objetos y referencias DOM

Abrir el archivo `app.js`.

Recordemos los estándares aprendidos:
- La constante del array va en **plural**: `purchases`.
- Cada elemento es un **objeto** con propiedades en singular: `title`, `amount`, `purchased`.
- El acceso se realiza mediante **notación de punto** (`purchase.title`, `purchase.amount`, `purchase.purchased`).

```javascript title="app.js" showLineNumbers
// 1. Array de objetos inicial
const purchases = [
  { title: "Pan y leche", amount: 12.00, purchased: true },
  { title: "Mochila para laptop", amount: 150.00, purchased: false },
  { title: "Cable USB-C", amount: 25.50, purchased: true }
];

// 2. Referencias a los elementos del formulario
const inpTitle = document.getElementById("inp-title");
const inpAmount = document.getElementById("inp-amount");
const chkPurchased = document.getElementById("chk-purchased");

// 3. Referencias a los contenedores de salida
const outResumen = document.getElementById("out-resumen");
const tblCompras = document.getElementById("tbl-compras");
```

## 4. Funciones de renderizado y lógica

### Renderizar el array de objetos con `for...of`
En `3-array-objetos.md` aprendimos a recorrer colecciones de objetos con el bucle **`for...of`**.

Esta función recibe cualquier lista de compras (la lista completa o una filtrada), itera sobre cada elemento `purchase` y construye filas `<tr>` leyendo sus propiedades con la notación de punto:

```javascript title="app.js" showLineNumbers
function renderizarTabla(lista) {
  let filasHtml = "";
  let numero = 1;

  for (const purchase of lista) {
    // Lectura de propiedades con notación de punto
    const estadoTexto = purchase.purchased ? "Comprado" : "Pendiente";

    filasHtml += "<tr>";
    filasHtml += "<td>" + numero + "</td>";
    filasHtml += "<td>" + purchase.title + "</td>";
    filasHtml += "<td>" + purchase.amount.toFixed(2) + "</td>";
    filasHtml += "<td>" + estadoTexto + "</td>";
    filasHtml += "</tr>";

    numero++;
  }

  tblCompras.innerHTML = filasHtml;
  outResumen.textContent = "Mostrando " + lista.length + " compra(s).";
}
```

### Calcular total gastado en compras realizadas
Recorremos el array sumando el valor de la propiedad `purchase.amount` de cada objeto cuyo estado `purchased` sea `true`:

```javascript title="app.js" showLineNumbers
function calcularTotalGastado() {
  let total = 0;
  for (const purchase of purchases) {
    if (purchase.purchased === true) {
      total += purchase.amount;
    }
  }

  return total;
}
```

### Modificar propiedades de los objetos
En `4-objetos.md` vimos que las propiedades de un objeto se modifican asignándoles un nuevo valor. Podemos actualizar la propiedad `purchased` de todos los objetos en el array:

```javascript title="app.js" showLineNumbers
function marcarTodasCompradas() {
  for (const purchase of purchases) {
    purchase.purchased = true;
  }
}
```

## 5. Event Listeners

Conectamos los botones y el formulario con nuestras funciones lógicas:

### Registrar nueva compra (Crear objeto e insertar)
Leemos los valores de los inputs, construimos un nuevo objeto literal con sus propiedades y lo agregamos al array `purchases`:

```javascript title="app.js" showLineNumbers
const btnRegistrar = document.getElementById("btn-registrar");

btnRegistrar.addEventListener("click", () => {
  const articulo = inpTitle.value.trim();
  const costo = Number(inpAmount.value);
  const comprado = chkPurchased.checked;

  if (articulo === "" || isNaN(costo) || costo <= 0) {
    alert("Por favor ingresa un artículo y un costo válido mayor a 0.");
    return;
  }

  const newPurchase = {
    title: articulo,
    amount: costo,
    purchased: comprado
  };

  // Insertar el nuevo objeto en el array
  purchases.push(newPurchase);

  // Limpiar campos del formulario
  inpTitle.value = "";
  inpAmount.value = "";
  chkPurchased.checked = false;

  // Actualizar la vista
  renderizarTabla(purchases);
});
```

### Mostrar todas las compras
```javascript title="app.js" showLineNumbers
const btnTodos = document.getElementById("btn-todos");

btnTodos.addEventListener("click", () => {
  renderizarTabla(purchases);
});
```

### Filtrar compras compradas y pendientes
Creamos un array auxiliar con los objetos según su propiedad booleana `purchased`:

```javascript title="app.js" showLineNumbers
const btnComprados = document.getElementById("btn-comprados");

btnComprados.addEventListener("click", () => {
  const articulosComprados = [];

  for (const purchase of purchases) {
    if (purchase.purchased === true) {
      articulosComprados.push(purchase);
    }
  }

  renderizarTabla(articulosComprados);
});

const btnPendientes = document.getElementById("btn-pendientes");

btnPendientes.addEventListener("click", () => {
  const articulosPendientes = [];

  for (const purchase of purchases) {
    if (purchase.purchased === false) {
      articulosPendientes.push(purchase);
    }
  }

  renderizarTabla(articulosPendientes);
});
```

### Calcular total gastado y marcar todos como comprados
```javascript title="app.js" showLineNumbers
const btnTotalGastado = document.getElementById("btn-total-gastado");
const btnComprarTodos = document.getElementById("btn-comprar-todos");

btnTotalGastado.addEventListener("click", () => {
  const total = calcularTotalGastado();
  outResumen.textContent = "Total gastado en compras: Bs. " + total.toFixed(2);
});

btnComprarTodos.addEventListener("click", () => {
  marcarTodasCompradas();
  renderizarTabla(purchases);
});

// Carga inicial al iniciar la página
renderizarTabla(purchases);
```

## 6. Verificar avance

1. Abrir `index.html` en el navegador **Google Chrome**.
2. Presionar <Keycap text="ctrl" /> + <Keycap text="shiftName" /> + <Keycap text="i" /> y abrir la pestaña **Console**.
3. **Carga inicial**: La tabla debe mostrar inmediatamente los 3 registros predefinidos (`Pan y leche`, `Mochila para laptop`, `Cable USB-C`).
4. Probar **Filtrar comprados**: La tabla debe mostrar únicamente `Pan y leche` y `Cable USB-C` (2 compras).
5. Probar **Filtrar pendientes**: La tabla debe mostrar únicamente `Mochila para laptop` (1 compra).
6. Probar **Total gastado**: Debe indicar `Total gastado en compras: Bs. 37.50` (12.00 + 25.50).
7. Probar **Registrar nueva compra**:
   - Ingresar Artículo: `Audífonos`, Costo: `80`, y dejar sin marcar la casilla.
   - Presionar **Registrar compra**: la tabla debe actualizarse automáticamente mostrando los 4 registros.
8. Probar **Marcar todo comprado**: El estado de `Mochila para laptop` y `Audífonos` debe cambiar de `Pendiente` a `Comprado`.

:::note
Si la tabla no se muestra o no responde a los clics, verifica en la consola que no existan errores rojos de nombres de variables o de `id` en las etiquetas HTML.
:::
