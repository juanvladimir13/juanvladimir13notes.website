En este codelab construiremos un catálogo rápido para una tienda de tecnología combinando un **array de objetos** para los artículos y un **array de cadenas primitivas** para las categorías disponibles.

---

## 1. Entorno de desarrollo

Presionar la tecla <Keycap text="windowName" /> y abrir la terminal **Git Bash**.

```bash
mkdir app-catalogo-productos
cd app-catalogo-productos
touch index.html app.js
code .
```

Abrir el archivo `index.html` y escribir la siguiente interfaz concisa:

```html title="index.html"
<html lang="es">

```

:::tip
El script `app.js` se enlaza antes de cerrar `</body>` para asegurar que el navegador cargue todos los elementos HTML antes de ejecutar el código.
:::

## 3. Arrays y referencias DOM

Abrir el archivo `app.js`. Declaramos el array primitivo de categorías y el array de objetos de productos:

```javascript title="app.js" showLineNumbers
// 1. Array primitivo de cadenas de texto
const categories = ["Periféricos", "Audio", "Cables", "Almacenamiento"];

// 2. Array de objetos
const products = [
  { name: "Mouse inalámbrico", price: 85, inStock: true },
  { name: "Teclado mecánico", price: 210, inStock: true },
  { name: "Cable HDMI 2m", price: 35, inStock: false }
];

const inpNombre = document.getElementById("inp-nombre");
const inpPrecio = document.getElementById("inp-precio");
const chkStock = document.getElementById("chk-stock");

const outCategorias = document.getElementById("out-categorias");
const outProductos = document.getElementById("out-productos");
const outTotal = document.getElementById("out-total");
```

## 4. Funciones de lógica y recorrido

Implementamos funciones simples para procesar ambas estructuras de datos:

```javascript title="app.js" showLineNumbers
function mostrarCategorias() {
  let categoriasHtml = "";
  for (let i = 0; i < categories.length; i++) {
    categoriasHtml += `<span>${categories[i]}</span> `;
  }
  outCategorias.innerHTML = categoriasHtml;
}

function mostrarProductos() {
  let itemsHtml = "";
  for (const prod of products) {
    const estado = prod.inStock ? "Disponible" : "Agotado";
    itemsHtml += `<li>${prod.name} - Bs. ${prod.price} (${estado})</li>`;
  }
  outProductos.innerHTML = itemsHtml;
}

function calcularTotalEnStock() {
  let total = 0;
  for (const product of products) {
    if (product.inStock) {
      total = total + product.price;
    }
  }
  return total;
}
```

## 5. Event Listeners

Conectamos los botones y el registro de nuevos productos:

```javascript title="app.js" showLineNumbers
const btnMostrar = document.getElementById("btn-mostrar");
const btnTotal = document.getElementById("btn-total");
const btnAgregar = document.getElementById("btn-agregar");

btnMostrar.addEventListener("click", () => {
  mostrarProductos();
});

btnTotal.addEventListener("click", () => {
  const total = calcularTotalEnStock();
  outTotal.textContent = `Total en stock: Bs. ${total}`;
});

btnAgregar.addEventListener("click", () => {
  const nombre = inpNombre.value.trim();
  const precio = Number(inpPrecio.value);
  const stock = chkStock.checked;

  if (nombre === "") {
    alert("Por favor ingrese un nombre y precio válido");
    return;
  }

  const nuevoProducto = { name: nombre, price: precio, inStock: stock };
  products.push(nuevoProducto);

  inpNombre.value = "";
  inpPrecio.value = "";
  chkStock.checked = true;

  mostrarProductos();
});

mostrarCategorias();
mostrarProductos();
```
