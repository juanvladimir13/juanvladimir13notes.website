## 🎯 Conceptos clave aplicados
- **Integración de estructuras**: Uso armónico de arrays primitivos (`string`, `number`) y arrays de objetos literales.
- **Acceso a datos**: Notación de corchetes con índice numérico (`array[i]`) y notación de punto para atributos de objetos (`objeto.propiedad`).
- **Recorrido eficiente**: Iteraciones con bucles `for` clásicos y `for...of`.
- **Algoritmos esenciales**: Acumuladores de totales, filtros condicionales e inserción dinámica con `.push()`.
- **Interactividad DOM**: Captura de eventos `click`, lectura de inputs y renderizado visual dinámico en la interfaz web.
