## Descripcion
Construir una pequeña _aplicación web_ ("Gestor de Calificaciones") mediante HTML estático, JavaScript y manipulación del DOM que:
- Almacena e inserta nuevos valores numéricos en un array
- Recorre y muestra los elementos del array junto con sus índices
- Calcula el promedio acumulado de las notas
- Determina los valores extremos (número mayor y menor)
- Implementa la búsqueda secuencial de elementos

## Que aprenderas
Fundamentos esenciales para el manejo de estructuras de datos y desarrollo frontend:
- Reglas y características de los arrays: homogeneidad, índices base 0 y longitud (`length`)
- Recorrido de colecciones con bucles clásicos (`for`, `while`) y modernos (`for...of`, `for...in`)
- Creación, acceso y modificación de objetos mediante notación de punto y corchetes
- Modelado de datos con arrays de objetos
- Manipulación del DOM: referencias con `document.getElementById`, lectura de inputs y actualización de la vista
- Conexión de funciones lógicas con eventos del usuario (`click`)
- Algoritmos fundamentales: acumulación, extremos (mayor/menor) y búsqueda secuencial

## Etapas
1. Características de los arrays _(definición, homogeneidad, índices, tamaño y bucles clásicos)_
2. Objetos _(propiedades clave-valor, notación de punto y corchetes)_
3. Array de objetos _(estructuras compuestas y bucles for...of / for...in)_
4. Operaciones con arrays _(codelab práctico: Gestor de Calificaciones con tipos primitivos)_
5. Codelab de array de objetos _(práctica con HTML, DOM, for...of y Directorio de Usuarios)_
