En este codelab construiremos una aplicación web para registrar y consultar un **array con datos numéricos primitivos** enfocado en una **Lista de Invitados (números de pase o boleto)**.

Pondremos en práctica los siguientes conceptos:
- Declaración de colecciones homogéneas en plural (`invitados`).
- Acceso por índice en base cero (`invitados[i]`) y uso de `.length`.
- Recorrido clásico con bucle `for`.
- Algoritmo fundamental de **búsqueda lineal** para ubicar un elemento en el array.
- Inserción de nuevos datos con `.push()` y actualización dinámica de la interfaz.

---

## 1. Entorno de desarrollo

Presionar la tecla <Keycap text="windowName" /> y abrir **Git Bash** o la terminal de su preferencia.

Crear la carpeta del proyecto e ingresar a ella:
```bash
mkdir app-lista-invitados
cd app-lista-invitados
touch index.html app.js
code .
```

## 2. Estructura HTML

Abrir el archivo `index.html` y escribir la estructura base con los campos de entrada, botones de acción y zonas de visualización:

```html title="index.html"
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Codelab - Lista de Invitados</title>
  </head>
  <body>

    <main>

      </section>

      <section>

        <input type="number" id="inp-buscar" min="1" required>
        <button id="btn-buscar">Buscar boleto</button>
      </section>

      <section>
        <h3>Operaciones</h3>

        <button id="btn-total">Total registrados</button>
      </section>

      <section>
        <h3>Resultados</h3>
        <p id="out-lista">Lista de invitados:</p>

      </section>
    </main>
    <footer></footer>
    <script src="app.js"></script>
  </body>

```

:::tip
El script `app.js` se ubica antes del cierre de `</body>` para que el navegador procese todos los elementos visuales antes de que JavaScript intente acceder a ellos.
:::

## 3. Declaración del array y referencias DOM

Abrir el archivo `app.js`.

Declaramos un array inicial con números de boleto o pases de los invitados y capturamos las referencias a los elementos del documento HTML:

```javascript title="app.js" showLineNumbers
const invitados = [102, 105, 108, 115, 120];

const inpInvitado = document.getElementById("inp-invitado");
const inpBuscar = document.getElementById("inp-buscar");

const outLista = document.getElementById("out-lista");
const outTotal = document.getElementById("out-total");
const outBusqueda = document.getElementById("out-busqueda");
```

:::danger
Comprueba que los identificadores en `document.getElementById("...")` coincidan con precisión con los atributos `id` declarados en `index.html`. Un error en una letra provocará que la variable valga `null`.
:::

## 4. Funciones de recorrido y búsqueda lineal

A continuación creamos funciones específicas para procesar la lista de invitados utilizando bucles `for` clásicos y la propiedad `.length`.

### Formatear y listar los números de pases
Recorremos el array desde el índice `0` hasta `invitados.length - 1` construyendo una cadena de texto:

```javascript title="app.js" showLineNumbers
function obtenerTextoInvitados() {
  let texto = "";
  for (let i = 0; i < invitados.length; i++) {
    const numero = invitados[i];
    texto = texto + "#" + numero + "  ";
  }
  return texto;
}
```

### Algoritmo de búsqueda lineal
Recorremos el array comparando cada elemento contra el número buscado. Si coincide, retornamos su posición de inmediato:

```javascript title="app.js" showLineNumbers
function buscarInvitado(numeroBuscado) {
  for (let i = 0; i < invitados.length; i++) {
    if (invitados[i] === numeroBuscado) {
      return "Encontrado: Boleto #" + invitados[i];
    }
  }

  return "No encontrado: " + numeroBuscado;
}
```

## 5. Event Listeners

Vinculamos la lógica programada con las interacciones del usuario mediante eventos `click`.

### Botón para mostrar la lista completa
```javascript title="app.js" showLineNumbers
const btnMostrar = document.getElementById("btn-mostrar");

btnMostrar.addEventListener("click", (evt) => {
  const texto = obtenerTextoInvitados();
  outLista.textContent = "Lista de invitados: " + texto;
});
```

### Botón para mostrar el total de registrados
```javascript title="app.js" showLineNumbers
const btnTotal = document.getElementById("btn-total");

btnTotal.addEventListener("click", (evt) => {
  const total = invitados.length;
  outTotal.textContent = "Total registrados: " + total;
});
```

### Botón para buscar un invitado
Leemos el número ingresado en el input de búsqueda, validamos que sea válido y ejecutamos la búsqueda:

```javascript title="app.js" showLineNumbers
const btnBuscar = document.getElementById("btn-buscar");

btnBuscar.addEventListener("click", (evt) => {
  const busqueda = Number(inpBuscar.value);

  if (!busqueda) {
    alert("Por favor ingrese un número de boleto para buscar");
    return;
  }

  const resultado = buscarInvitado(busqueda);
  outBusqueda.textContent = "Resultado de búsqueda: " + resultado;
});
```

### Botón para registrar un nuevo invitado
Leemos el valor numérico del input, validamos que no esté en blanco, insertamos el nuevo número al final del array con `.push()` y refrescamos la lista:

```javascript title="app.js" showLineNumbers
const btnAgregar = document.getElementById("btn-agregar");

btnAgregar.addEventListener("click", (evt) => {
  const valor = Number(inpInvitado.value);

  if (!valor) {
    alert("Por favor ingrese un número de boleto válido");
    return;
  }

  invitados.push(valor);

  inpInvitado.value = "";

  const texto = obtenerTextoInvitados();
  outLista.textContent = "Lista de invitados: " + texto;
  outTotal.textContent = "Total registrados: " + invitados.length;
});
```

:::tip
Al invocar `invitados.push(valor)`, el nuevo número se agrega en la posición que corresponde al tamaño actual del array y la propiedad `invitados.length` aumenta automáticamente en 1.
:::

## 6. Verificar avance

1. Abrir el archivo `index.html` en el navegador **Google Chrome**.
2. Presionar <Keycap text="ctrl" /> + <Keycap text="shiftName" /> + <Keycap text="i" /> para abrir las herramientas de desarrollo y seleccionar la pestaña **Console**.
3. Presionar el botón **Mostrar lista**: se deben listar los 5 números iniciales `#102  #105  #108  #115  #120`.
4. Presionar el botón **Total registrados**: debe mostrar `Total registrados: 5`.
5. Escribir `105` en el campo de búsqueda y hacer clic en **Buscar boleto**: debe mostrar `Resultado de búsqueda: Encontrado: #105`.
6. Escribir un número inexistente como `999` y buscar: debe mostrar `Resultado de búsqueda: No encontrado: #999`.
7. Ingresar `130` en el campo superior y hacer clic en **Registrar boleto**: la lista se refrescará con `#130` y el total mostrará `6`.

:::note
Si al hacer clic en los botones no sucede nada, revisa la consola del navegador para verificar que no existan errores rojos producidos por nombres de variables o `id` no coincidentes.
:::
