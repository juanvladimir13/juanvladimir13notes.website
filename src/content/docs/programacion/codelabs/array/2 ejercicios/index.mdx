## 🎯 Conceptos clave aplicados
- **Declaración en plural**: Nombres representativos para colecciones (`calificaciones`, `gastos`, `temperaturas`, `invitados`, `edades`).
- **Homogeneidad de primitivos**: Elementos del mismo tipo primitivo (`number` o `string`).
- **Índice base 0 y longitud**: Uso de `[i]` y `.length`.
- **Bucles clásicos**: Recorridos con `for (let i = 0; i < array.length; i++)`.
- **Algoritmos fundamentales**:
  - Acumulación y cálculo de promedios.
  - Búsqueda de extremos (valores máximos y mínimos).
  - Búsqueda lineal secuencial.
  - Conteo condicional basado en filtros `if`.
- **Manipulación del DOM**: Conexión entre eventos de usuario (`click`), lectura de `input` y actualización de texto (`textContent`).
