## Estructura de archivos y carpetas

Presionar la tecla <Keycap text="windowName" /> y escribir **Git Bash**

Crear una carpeta
```bash
mkdir contador-likes
```

Ingresar a la carpeta
```bash
cd contador-likes
```

Crear los archivos `index.html` y `counter.js`

```bash 
touch index.html counter.js
```

Abrir el editor de codigo **Visual Studio Code** en la carpeta actual

```bash
code .
```
