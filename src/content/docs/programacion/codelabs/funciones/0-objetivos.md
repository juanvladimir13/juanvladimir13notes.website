## Descripcion
Construir una pequeña _aplicación web_ mediante HTML estático, JavaScript básico y event listeners que:
- Captura datos
- Procesa los datos
- Muestra resultados

## Que aprenderas
Fundamentos esenciales para el desarrollo frontend:
- Obtención de referencias DOM y la respuesta a eventos
- Obtención y manipulation de los valores de las etiquetas HTML
- Declaración y uso de funciones con y sin parámetros

## Etapas
1. Entorno de desarrollo _(estructura de archivos y carpetas)_
2. Formulario de datos HTML
3. Manipulación del DOM y funciones listeners
4. Llamada a funciones y actualización de la vista
