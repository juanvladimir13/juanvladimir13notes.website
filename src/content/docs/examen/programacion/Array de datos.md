### Ejercicio 1
> Crear un array de promedios finales de cada trimeste y mostrar la nota del segundo trimestre

### Solucion
```typescript
const notas: number[] = [
  51, 80, 95 
];
console.log(notas[1]);
```

### Ejercicio 2
> Crear un array de tus 3 mejores amig@s y muestra a tu mejor amigo

### Solucion
```typescript
const amigos: string[] = [
  'Ana', 'Juan', 'Maria'
];
console.log(amigos[0]);
```

### Ejercicio 3
> Crear un array con los gastos que realisaste en el dia y muestra el numero mayor

### Solucion
```typescript
const gastos: number [] = [
  1, 26, 13
];
console.log(gastos[1]);
```
