## Descripcion

Construir una _página web_ maquetada con **HTML semántico** y estilizada con **CSS**, aplicando la estructura correcta de un documento, las distintas formas de incluir estilos y los selectores fundamentales de CSS.

## Que aprenderas
Fundamentos esenciales para el diseño y maquetación web:
- Estructura de un proyecto web _(archivos y carpetas)_
- Estructura básica de un documento HTML
- Formas de incluir CSS en HTML
- El modelo de caja _(box model)_
- Sintaxis de una regla CSS
- Selectores CSS: tipo, clase, id y atributo

## Etapas
1. Entorno de desarrollo _(estructura de archivos y carpetas)_
2. Estructura básica del documento HTML
3. Formas de incluir CSS en HTML
4. CSS: modelo de caja y sintaxis de una regla
5. Selectores CSS _(tipo, clase, id y atributo)_
