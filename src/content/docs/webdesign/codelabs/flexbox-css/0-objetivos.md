## Descripcion

Construir una _página web_ utilizando **Flexbox** para posicionar elementos HTML.

## Que aprenderas
Fundamentos esenciales para el diseño y maquetación web:
- Terminologia (container y items)
- Propiedades por defecto
- Propiedad `gap`
- Propiedad `align-items`
- Propiedad `justify-content`
- Propiedad `align-self`
- Propiedad `flex-wrap`

1. Estructura del proyecto
2. Terminologia de flex

4. Alineacion de elementos
